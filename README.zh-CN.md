# SaveOne

[English](README.md) | [简体中文](README.zh-CN.md)

**一个链接，一个公开视频。**

SaveOne 是一款轻量级在线视频下载工具，支持逐个保存来自 YouTube、TikTok、Instagram、X 和 Reddit 的公开视频。粘贴链接、确认视频信息，即可下载来源平台当前提供的最佳可用文件。

[立即使用 SaveOne](https://saveone.pro/zh-cn/) · [报告问题或提出建议](../../issues)

![SaveOne 在线视频下载工具](screenshots/desktop-seo-home.png)

## SaveOne 能做什么

- 支持 YouTube、TikTok、Instagram、X 和 Reddit 的公开视频
- 下载前展示标题、来源、时长和预估文件大小
- 自动选择最佳可用画质，并在条件允许时合并视频和音频
- SaveOne 不会添加水印，但原视频本身可能带有水印
- 无需注册 SaveOne 账号，不提供批量下载
- 支持英语、西班牙语、葡萄牙语、法语、德语、日语、韩语和简体中文
- 适配现代桌面端和移动端浏览器

## 使用方法

1. 打开 [saveone.pro](https://saveone.pro/zh-cn/)。
2. 粘贴一个受支持的公开视频链接，点击“查找视频”。
3. 确认预览信息，开始下载，文件准备完成后及时保存。

## 当前限制

- 每次处理一个公开视频
- 单个视频最长 30 分钟、最大 500 MB
- 不支持播放列表、用户主页、私密内容、必须登录才能访问的内容或批量下载
- 临时文件会在大约 30 分钟后自动删除
- 实际可用性和画质取决于来源平台当时提供的内容

来源平台可能随时调整网页结构、访问规则或媒体格式，因此现在可以使用的链接以后也可能暂时失效。部分 Instagram 视频可能只向服务器提供无声画面；SaveOne 如果能够提前识别，会在下载前提示并征求确认。
